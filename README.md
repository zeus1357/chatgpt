# 블루투스 파일 감지 (BtFileWatch)

블루투스로 폰에 들어오는 파일을 감지해 알려 주고, Claude 대화창으로 넘길 수 있게 해 주는 앱입니다.

| 폴더 | 내용 |
| --- | --- |
| `ios/` | 아이폰 앱 (SwiftUI) |
| `sender/` | 아이폰으로 파일을 보내는 웹 페이지 (PC·Mac·안드로이드의 Chrome/Edge) |
| `app/` 등 최상위 | 안드로이드 앱 (Kotlin) |

## 아이폰

### 먼저 알아둘 점: 아이폰은 일반 블루투스 파일 전송을 받지 못합니다

아이폰이 다른 기기와 블루투스로 "연결"되는 것은 맞지만, 그 연결로 할 수 있는 일은 애플이 정해 둔 것(통화·음악·키보드·테더링 등)뿐입니다. PC나 안드로이드의 "블루투스로 파일 보내기"가 쓰는 규격(OBEX Object Push)은 아이폰이 지원하지 않고, 앱이 그 기능을 추가할 수도 없습니다. 또 아이폰 앱은 다른 앱(에어드롭, 파일 앱 등)이 받은 파일을 감시할 수 없습니다.

그래서 이 앱은 **앱이 직접 블루투스 LE로 파일을 받는 방식**으로 만들었습니다. 보내는 쪽은 기기의 기본 "블루투스로 보내기" 대신 `sender/`의 웹 페이지를 사용합니다.

### 동작 방식

1. 아이폰 앱을 열면 블루투스 LE로 "BtFile"이라는 이름의 수신 서비스를 알립니다.
2. 보내는 기기의 Chrome/Edge에서 `sender/index.html`을 열고 아이폰을 연결한 뒤 파일을 고릅니다.
3. 아이폰 앱이 파일을 받아 저장하고, 알림을 띄우고, **바로 공유 창을 엽니다. 여기서 Claude를 고르면 대화창에 첨부됩니다.**
4. 받은 파일은 앱 목록에 남고, 「파일」 앱의 "나의 iPhone → 블루투스 파일 감지 → Received"에서도 보입니다.

### 설치 (Mac과 Xcode 필요)

아이폰 앱은 Mac의 Xcode로만 설치할 수 있습니다.

```sh
brew install xcodegen
cd ios && xcodegen generate
open BtFileWatch.xcodeproj
```

Xcode에서 BtFileWatch 타깃의 Signing & Capabilities에 본인 Apple ID 팀을 지정하고, 아이폰을 연결해 실행합니다. 무료 Apple ID로 설치한 앱은 7일마다 다시 설치해야 합니다.

### 보내는 쪽 사용법

`sender/` 폴더를 내려받아 Chrome 또는 Edge에서 `index.html`을 엽니다. 파일로 직접 열었을 때 블루투스 버튼이 동작하지 않으면 그 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 여세요.

### 알려진 한계

- **연결할 때는 아이폰 앱이 화면에 떠 있어야 합니다.** 백그라운드에서는 iOS가 수신 서비스 알림을 숨겨서 보내는 쪽이 아이폰을 찾지 못합니다.
- **느립니다.** 블루투스 LE라 초당 수십 KB 수준이어서 사진·문서 정도에 적합하고, 동영상 같은 큰 파일에는 맞지 않습니다.
- 아이폰의 Safari·Chrome은 Web Bluetooth가 없어서 아이폰끼리는 이 페이지로 보낼 수 없습니다.
- iOS는 공유할 앱을 미리 지정할 수 없어서, 공유 창에서 Claude를 직접 골라야 합니다.

## 안드로이드

안드로이드 폰이 **블루투스로 파일을 받으면 이를 감지해서 알림을 띄우고 기록을 남기는** 앱입니다.

Android 11 이상에서 동작합니다. 프로젝트 파일은 저장소 최상위(`app/`, `build.gradle.kts` 등)에 있습니다.

### 동작 방식

1. 포그라운드 서비스가 `MediaStore`(기기의 파일 목록)에 새 파일이 등록되는지 지켜봅니다.
2. 새 파일이 아래 중 하나에 해당하면 블루투스 수신 파일로 판단합니다.
   - 파일을 저장한 앱이 시스템 블루투스 앱 (`com.android.bluetooth` 등)
   - 경로에 `Bluetooth` 폴더가 포함됨 (예: `Download/Bluetooth/`)
3. 파일 크기가 더 이상 변하지 않으면 수신 완료로 보고 알림을 띄우고, 앱 화면의 기록에 추가합니다.

### Claude 대화창에 첨부하기

수신 알림을 누르면 받은 파일이 **Claude 앱의 대화창에 첨부된 상태로** 열립니다. 앱 화면의 기록에서도 각 파일 아래 **Claude로 보내기** 버튼으로 같은 동작을 할 수 있습니다.

- 안드로이드는 백그라운드 앱이 다른 앱 화면을 마음대로 띄우는 것을 막기 때문에, 완전 자동이 아니라 알림을 한 번 눌러야 합니다.
- Claude 앱이 설치되어 있지 않거나 해당 파일 형식을 받지 않으면 일반 공유 창이 대신 열립니다.

### 설치

1. GitHub의 **Actions → Build** 실행 결과에서 `bt-file-watch-debug-apk`를 내려받아 폰에 설치합니다.
   (직접 빌드: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`)
2. 앱을 열고 **파일 접근 권한 허용하기**를 눌러 "모든 파일에 대한 접근"을 켭니다.
3. 알림 권한을 허용하고 **감시 시작**을 누릅니다.

재부팅 후에도 감시가 켜져 있었다면 자동으로 다시 시작됩니다.

### 권한

| 권한 | 이유 |
| --- | --- |
| 모든 파일에 대한 접근 | 블루투스로 받은 파일은 PDF·ZIP 같은 일반 파일일 수 있는데, 이런 파일은 이 권한 없이는 다른 앱이 볼 수 없습니다 |
| 알림 | 수신 감지 알림 표시 |
| 포그라운드 서비스 / 부팅 완료 | 백그라운드에서 계속 감시 |

앱은 인터넷 권한이 없으며, 파일 내용을 읽거나 외부로 보내지 않습니다.

### 알려진 한계

- 제조사에 따라 배터리 최적화가 서비스를 종료할 수 있습니다. 감지가 끊기면 설정에서 이 앱의 배터리 사용을 "제한 없음"으로 바꿔 주세요.
- 감시가 꺼져 있던 동안 받은 파일은 알리지 않습니다.
- 블루투스 앱이 `Bluetooth` 폴더가 아닌 곳에 저장하면서 저장한 앱 정보도 숨기는 기기에서는 감지하지 못할 수 있습니다.
